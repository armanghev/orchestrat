# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately. Do not open a public issue, pull
request or discussion about them.

- **GitHub:** open the repository's **Security** tab and choose **Report a
  vulnerability** (GitHub private vulnerability reporting).
- **Email:** [arman@orchestrat.dev](mailto:arman@orchestrat.dev).

Include what you found, the affected version or commit, steps to reproduce,
and the impact you expect. You will get a reply as soon as possible. Please
give us a reasonable time to ship a fix before you disclose the issue
publicly.

## Supported versions

Only the latest release gets security fixes. Upgrade to it before reporting,
and check whether the issue still reproduces there.

## Bounty

There is no bug bounty program, and reports are not paid.
